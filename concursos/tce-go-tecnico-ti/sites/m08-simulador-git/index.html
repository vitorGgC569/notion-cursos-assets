Módulo 8 · DevOps e Engenharia de Entrega

Simulador de Git

Digite comandos de Git e veja o grafo de commits mudar. Cumpra as oito missões: commit, branch, merge com commit de junção, conflito, rebase, revert, stash e reset. Nada sai do seu navegador.

ana@dev:~/projeto$

Limites do simulador

É um modelo didático em JavaScript, não o Git. Arquivos têm uma só linha; o conflito é detectado quando as duas branches mudam o mesmo arquivo de formas diferentes; rebase com conflito não é continuado; os hashes são inventados; não há remoto (push, pull, fetch), reflog, bisect, hooks nem submódulos. As respostas do modelo foram conferidas contra o Git real no Laboratório L10 (veja o módulo).
