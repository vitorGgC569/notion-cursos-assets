== 3. Validacao da cadeia ==
$ openssl verify -CAfile ca.crt servidor.crt
servidor.crt: OK
$ openssl verify servidor.crt   (sem informar a CA)
  C=BR, O=Curso TCE-GO TI, CN=localhost

  error servidor.crt: verification failed

== 4. Certificado vencido: verificacao numa data futura (-attime) ==
$ openssl verify -attime <hoje + 200 dias> -CAfile ca.crt servidor.crt
  C=BR, O=Curso TCE-GO TI, CN=localhost
  error 10 at 0 depth lookup: certificate has expired
  error servidor.crt: verification failed
