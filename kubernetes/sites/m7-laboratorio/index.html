Módulo 7 · Git e GitHub

Laboratório guiado

Tempo estimado: 2 a 3 horas · Cenário: você entrou em um time que guarda os manifestos de uma aplicação no Git. Antes de mexer em qualquer coisa, precisa dominar o ciclo de trabalho, as branches, os conflitos, o desfazer e a troca com um remoto. Todos os laboratórios usam só o seu usuário e foram executados em Linux com Git 2.47. Para não depender de conta no GitHub, o "servidor" é um repositório local do tipo bare (sem arquivos de trabalho), que se comporta exatamente como o GitHub para o Git. As saídas mostradas são as reais; os hashes de commit (as sequências como 0d28f4b) mudam de pessoa para pessoa, e as datas também. Só o bônus do laboratório 7, com o GitHub de verdade, não foi executado, porque exige a sua conta.
