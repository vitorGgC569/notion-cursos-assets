Módulo 2 · Linux

Terminal Linux: navegar e manipular arquivos

Um terminal de verdade (simulado) para praticar pwd, ls, cd, mkdir, cp, mv e rm. Cada tarefa é verificada automaticamente. Use a seta para cima para repetir comandos e Tab para completar.

Reiniciar volta o sistema de arquivos ao início, mas mantém as tarefas concluídas.
