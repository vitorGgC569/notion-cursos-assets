Módulo 19 · Ingress e Gateway API

Laboratório guiado

Dezesseis laboratórios em um cluster kind de três nós (um control plane e dois workers): o Traefik como controller de Ingress, regras por caminho (Prefix e Exact) e por host (inclusive curinga), backend padrão, TLS com Secret, diagnóstico de Ingress quebrado, Envoy Gateway com GatewayClass e Gateway, HTTPRoute com allowedRoutes, precedência, match de cabeçalho, redirect, canário com pesos, ReferenceGrant entre namespaces, HTTPS no Gateway e migração com ingress2gateway. Os comandos foram executados com kind v0.33.0, kubectl v1.37.1, Helm v4.3.1 e nós em Kubernetes v1.37.0; as saídas são as reais, condensadas quando longas.
