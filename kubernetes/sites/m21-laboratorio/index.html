Módulo 21 · Autoscaling e Metrics Server

Laboratório guiado

Treze laboratórios em um cluster kind de três nós (um control plane e dois workers): o kubectl top sem métricas, a instalação do Metrics Server e o erro de certificado do kind, a Metrics API crua, o primeiro HPA, a carga que leva o php-apache de 1 a 7 réplicas e a descida depois da janela de 300 s, o alvo unknown sem requests, duas métricas com behavior, o redimensionamento no lugar, o VPA em modo Off e InPlaceOrRecreate, Pods Pending por falta de CPU, três autoscalings quebrados para consertar e a limpeza. Os comandos foram executados com kind v0.33.0, kubectl v1.37.1, Helm v4.3.1, Metrics Server v0.9.1, VPA 1.8.1 e nós em Kubernetes v1.37.0; as saídas são as reais, condensadas quando longas.
