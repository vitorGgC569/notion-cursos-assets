Módulo 10 · Docker

Laboratório guiado

Oito laboratórios. Você prova que o docker rm apaga os dados, guarda dados em volumes e bind mounts, faz backup, vê o DNS funcionar só na rede criada por você, publica portas, usa o netshoot e fecha com um banco PostgreSQL que sobrevive à troca do contêiner. Todos foram executados de verdade com Docker 29, e as saídas mostradas são reais.

Tempo estimado: 3 a 4 horas · Cenário: você vai fazer os dados sobreviverem a um contêiner, montar uma rede em que os contêineres se acham pelo nome e, no fim, subir um banco de dados que só a sua aplicação enxerga. Todos os comandos foram executados em Linux com Docker Engine 29.9. As saídas mostradas são as reais (resumidas quando eram longas). IDs, horários e endereços IP mudam um pouco de máquina para máquina. Atenção: nomes de contêiner precisam ter pelo menos 2 caracteres (por isso alfa e beta, e não a e b). No Docker Desktop, o caminho /var/lib/docker/volumes e o ip do host ficam dentro da VM; os laboratórios avisam quando um passo muda.
