Módulo 11 · Docker Compose e Registries

Laboratório guiado

Oito laboratórios. Você sobe uma aplicação com Redis só com um arquivo, prova a diferença entre down e down -v, usa variáveis e perfis, reproduz uma falha de dependência, sobe o seu registry, protege com senha, usa o skopeo e fecha rodando a aplicação a partir da imagem do seu registry. Todos foram executados de verdade com Docker 29 e Compose v5, e as saídas mostradas são reais.

Tempo estimado: 3 a 4 horas · Cenário: você vai descrever uma aplicação com um arquivo, controlar o ciclo de vida dela, separar configuração do código e, na segunda metade, montar e proteger o seu próprio registry para depois rodar a aplicação a partir dele. Todos os comandos foram executados em Linux com Docker Engine 29.9 e Docker Compose v5.6.1. As saídas mostradas são as reais, condensadas quando eram longas (sem um terminal interativo, o Compose repete algumas linhas de progresso, e eu mostrei cada uma só uma vez; no seu terminal, a saída é animada e mais curta). IDs, horários e endereços IP mudam de máquina para máquina. Os arquivos ficam em ~/modulo11, e cada laboratório tem a sua pasta. As portas usadas são 8080, 9090 e 5000; se alguma estiver ocupada no seu computador, troque o número do lado do host.
